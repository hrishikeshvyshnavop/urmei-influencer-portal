# Client change requests

One folder per request, named for its topic in kebab-case. The workflow that fills them is `workflows/change-request/SKILL.md`.

| File | Written at | Holds |
| --- | --- | --- |
| `REQUIREMENT.md` | 1. Intake | The client's message verbatim, scope (MVP / post-MVP), code touched, open questions with options and their answers, status |
| `ANSWERS.md` | 2. Clarify | The short answers summary to send to the client |
| `FLOWS.md` | 3. Design | Every Figma flow, its sub-section and frames, status, and any old → new frame-name table |
