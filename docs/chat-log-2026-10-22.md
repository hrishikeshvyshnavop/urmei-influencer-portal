## 5. Reusable Figma comments workflow

- Added [`workflows/figma-comments/references/reusable-figma-comments.md`](../workflows/figma-comments/references/reusable-figma-comments.md), a version of `figma-comments` that works in any project.
- A settings table replaces the URMEI-specific values: `FILE_KEY`, `OWNER`, `SHARED_COMPONENTS`, `DECISIONS`, `LOG`, `FIGMA_RULES`, `REFINE_STEP` and `PREFIX`.
- All five scripts are inlined (`lib`, `watch`, `open`, `reply`, `comment`).
  - Settings come from environment variables: `FIGMA_FILE_KEY` (required), `FIGMA_TOKEN` or `.figma-token`, `COMMENT_PREFIX` and `POLL_SECONDS`.
  - Run the scripts from the project root.
  - All five passed `node --check`. They haven't been run against a real Figma file.
- Linked from `workflows/README.md`.
